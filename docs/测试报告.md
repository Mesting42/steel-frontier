## 已修复问题

- 固定步长令速射武器的间隔被量化，实际射速低于配置；改为保留冷却余量。
- 基地直击与范围伤害可能叠加；直击基地单独结算。
- 小屏菜单车库入口与页脚重叠；矮横屏改用自然文档流。
- 合成键盘事件以 Window 为目标时的类型判断；改为检查实际 Element。
- 训练武器切换后的 HUD 延迟与技能切换后的选择状态；即时同步并保留当前武器。
- 奖励和已购商店内容在刷新后的恢复；保存明确检查点阶段和库存快照。
- 私有合并网格、临时特效和关卡资源的释放；共享缓存与私有资源分开管理。
- 敌军标签覆盖 HUD 的层级；状态与控件层置于战场标签层之上。
- 紧急护盾超过上限后下一帧被截断；改为直接补满，并增加回归测试。

## 已知限制

- 美术为原创程序模型与程序材质，具有结构、材质、阴影和机械动画；不等同于人工雕刻、烘焙的高面数影视资产。
- 未完成实体移动设备、Safari/WebKit 和低端 GPU 的性能验证；较弱设备建议选择“流畅”图形质量。
- 全战役通关由自动输入实战验证，尚未进行多名真人的难度平衡测试；自动驾驶能读取完整测试状态，存活率不代表新玩家。
- 已检查六战生命周期、弹丸/特效上限及声音节点释放，未进行数小时连续的实体设备压力测试。
- 中文使用系统字体，不同操作系统的字形会略有差异。
- 检查点从安全整备或战斗起点恢复，不保存正在进行的波次。这是设计规则，刷新会重新部署本战。
- 本地纪录只属于当前浏览器与站点端口；清理站点数据会删除，5173 与 4173 的记录相互独立。

视觉复核以用户确认的文字方案和三端截图为依据，结论为 `ship`；详情见 `视觉复核.md`。按项目要求，未使用预制 Agent 工作流。
