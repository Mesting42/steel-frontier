二、游戏定位与完整流程

这是一款第三人称高位俯视角的坦克动作防守游戏。

玩家驾驶一辆可强化的坦克，保护战区指挥基地。敌军从多个方向进攻，玩家需要驾驶走位、独立瞄准、破坏墙体、利用掩体、拦截突击单位，并在战斗之间选择装备与路线。

核心乐趣：
- 驾驶和射击直接、灵活、有重量感。
- 墙体可以打穿，战场会随战斗发生变化。
- 玩家需要在追击敌人与保护基地之间作出判断。
- 不同主炮、技能和被动装备能形成不同构筑。
- 每局路线、地图组合、敌人、商店和奖励有变化。
- 最终拥有明确的胜利目标。

一局战役控制在约 15–25 分钟，完成：
开始战役 → 选择战场路线 → 防守与战斗 → 获得资源和强化 → 整备与修理 → 更危险的战区 → 最终 Boss → 胜利结算。

三、画面与原创主题

采用高分辨率、非像素风的精致风格化 3D 美术。

整体表现为有真实材质和空间层次的军事模型战场：
- 喷漆金属、装甲接缝、橡胶履带、混凝土、砖墙、沙土和积水。
- 克制的色彩搭配，清楚的敌我识别。
- 有层次的动态灯光、阴影、炮口火光、爆炸和烟尘。
- 风格偏精致模型与动作游戏，不追求写实军事模拟。

至少制作三个视觉区域：
1. 边境工业区：仓库、砖墙、管线、货场和维修设施。
2. 荒原补给线：沙土、岩体、废弃车辆、油罐和阵地。
3. 冻原能源站：积雪、钢铁设施、冷色灯光和大型机械。

每个区域的地图结构、材质、灯光、装饰和环境音需要形成明显差异。

禁止：
- 像素风。
- 用纯色方块作为最终坦克。
- 用同一个模型换颜色代替所有敌人。
- 使用默认几何体直接充当最终场景。
- 满屏霓虹和过度光晕。
- 大量烟尘遮住敌人、弹道和危险提示。

四、坦克造型与动画

玩家坦克需要具有清楚的结构：
- 履带。
- 车体。
- 独立旋转的炮塔。
- 炮管。
- 装甲板与接缝。
- 灯光、排气和必要的机械细节。

至少表现：
- 行驶中的履带运动。
- 起步、停止和转向反馈。
- 炮塔跟随瞄准方向旋转。
- 射击时炮管后坐。
- 受击时短促反馈。
- 低耐久时的损伤与轻烟。
- 被摧毁后的爆炸和残骸。

不同武器需要改变炮管、发射部件或能量装置，不能换了武器后外观完全没有变化。

敌军至少使用数种具有不同轮廓的车体，例如轻型侦察车、重装坦克、自行火炮和工程车辆。

五、驾驶与独立瞄准

电脑操作：
- WASD：自由移动。
- 鼠标：独立瞄准。
- 鼠标左键按住：持续射击。
- Space：短距离机动冲刺。
- E：使用主动技能。
- Q：切换携带的主武器。
- Esc：暂停。

手机和平板：
- 左侧虚拟摇杆控制移动。
- 右侧虚拟摇杆控制瞄准，推动时持续射击。
- 独立的技能、冲刺、换武器与暂停按钮。
- 双摇杆支持同时操作。

驾驶采用适合动作游戏的自由移动：
- 输入方向决定移动方向。
- 车体朝移动方向平滑转动。
- 炮塔可以独立朝其他方向射击。
- 允许边移动边瞄准。
- 不使用必须先原地转向才能前进的复杂驾驶方式。

角色要有适度加速与减速，但不能惯性过大。
移动、车体朝向和碰撞体保持一致。
履带碰墙后正确滑动或停止，不能穿墙、弹飞或持续抖动。

机动冲刺：
- 有冷却。
- 用于快速调整位置。
- 默认不穿过实体墙。
- 如果包含短暂无敌，必须有明显视觉提示，并与实际判定同步。

六、主炮与射击

主武器采用无限基础弹药，不设置弹匣和换弹流程。

不同武器可以有清楚的射击间隔、蓄能或过热规则，但不能无提示地停止攻击。
任何特殊冷却都需要显示原因和恢复进度。

至少制作六种差异明确的武器：

1. 标准榴弹炮
- 射速与伤害均衡。
- 炮弹命中后造成小范围爆炸。
- 初始即可使用。

2. 双联速射炮
- 高频发射小型弹丸。
- 单发伤害低。
- 适合追踪轻型敌人与持续压制。

3. 穿甲磁轨炮
- 射速较慢。
- 发射高速穿透弹。
- 擅长处理装甲目标和直线上的多个敌人。

4. 散射破片炮
- 近距离扇形攻击。
- 对近身集群有效。
- 距离增加后命中与伤害效率降低。

5. 导弹发射架
- 发射具有有限追踪能力的导弹。
- 有范围伤害。
- 不能隔着实体墙无限追踪。

6. 电弧发生器
- 攻击在邻近敌人之间跳跃。
- 对成群单位有效。
- 拥有与实体炮弹明显不同的声音和特效。

武器要在射速、射程、弹道、范围、穿透和战术用途上形成差异。

玩家最多携带两种主武器，可在战斗中切换。
拾取第三种武器时明确选择替换对象，并显示新旧武器的真实预览和说明。

七、弹道、命中与伤害

这是核心系统，必须准确。

要求：
- 炮弹从实际炮口位置发出。
- 炮管方向、发射方向与视觉弹道一致。
- 不能从坦克中心或炮塔后方发射。
- 炮口贴墙时不能穿墙生成炮弹。
- 高速炮弹使用连续或扫掠碰撞。
- 检测最近命中物，避免先打到墙后方敌人。
- 同一次命中不能重复扣血。
- 激光、电弧、导弹和范围爆炸各自遵循明确规则。

爆炸效果：
- 有清楚的作用范围。
- 对实体掩体采用合理遮挡规则。
- 能破坏的物体与不能破坏的物体容易辨认。
- 特效大小与实际伤害范围基本一致。

耐久与护盾：
- 先消耗护盾，再扣除耐久。
- 受击后即时更新数值。
- 如果存在保护时间，明确显示闪烁、轮廓或状态。
- 不允许出现无提示的“炮弹命中却没有扣耐久或护盾”。
- 伤害减免和无敌规则要能解释。

玩家普通攻击不伤害己方基地，避免守基地时因正常拦截误毁基地。
爆炸桶等环境连锁伤害是否影响基地，需要统一规定并明确提示。

八、可破坏地形与战场交互

至少实现：

1. 砖墙
- 可被炮火分段摧毁。
- 破坏后真实开放通路和射界。
- 残留碎片只作为装饰，不再错误阻挡移动。

2. 钢铁墙体
- 阻挡坦克与普通弹药。
- 与砖墙外观明显不同。

3. 沙袋与低矮掩体
- 提供局部遮挡。
- 耐久较低，可被摧毁。

4. 爆炸桶或燃料罐
- 被击中后爆炸。
- 可以引发有限连锁反应。
- 有明确危险外观。

5. 废弃车辆或机械残骸
- 提供掩体。
- 部分可破坏。
- 破坏后改变战场空间。

6. 地形区域
- 泥地降低移动效率。
- 冰面带来适量滑动。
- 水域或深坑阻止通行。

7. 修理与补给设施
- 可以靠近并交互。
- 显示价格或使用次数。
- 战斗中使用时承担明确风险。

所有阻挡移动和弹药的物体，需要在外观与碰撞上保持一致。

九、基地与防守规则

每个防守战场都有清楚可见的己方基地。

基地拥有：
- 独立耐久条。
- 受击反馈。
- 低耐久警报。
- 可恢复的护盾或防御升级。
- 被摧毁后的明确失败状态。

敌人的进攻目标需要有区别：
- 部分直接攻击基地。
- 部分优先追击玩家。
- 部分破坏墙体，打开进攻路线。
- 部分从侧翼突入。

每波开始前显示：
- 大致进攻方向。
- 敌人类型。
- 波次信息。

敌人不能在基地旁或玩家脚下无提示生成。
出生区需要提前预警，并给予足够反应时间。

战斗结束条件：
- 当前波次敌人全部处理完毕。
- 不存在卡在地图外或无法到达的敌人。
- 完成所有波次后正确发放奖励。

玩家或基地被摧毁都结束本局。
结算清楚说明失败原因。

十、敌军与 AI

至少制作七种敌人：

1. 轻型侦察车
- 速度快、耐久低。
- 绕路接近基地或骚扰玩家。

2. 标准坦克
- 攻防均衡。
- 使用掩体并持续推进。

3. 重装坦克
- 速度慢、装甲高。
- 正面威胁大。
- 可设计侧后方弱点。

4. 自行火炮
- 保持距离。
- 发射有落点预警的间接火力。

5. 突击爆破车
- 冲向基地或玩家。
- 靠近后引爆。
- 轮廓和声音清楚，给予拦截时间。

6. 工程支援车
- 修理或强化附近敌人。
- 优先处理有战术价值。

7. 干扰车辆
- 在局部区域制造干扰或减速。
- 效果范围与持续时间可见。

AI 必须：
- 能围绕墙体寻路。
- 在砖墙被破坏后更新路径。
- 发现原路线不可通行时重新规划。
- 射击前检查射界。
- 不持续朝无法打穿的墙后玩家开火。
- 避免所有敌人挤成一团或互相永久堵住。
- 不无提示获得全地图精确视野。

难度提升主要来自组合、路线和协同，不只是成倍增加生命值。

十一、战役与路线选择

战役分为三个区域，共六场主要战斗。

每个区域包含：
- 一场普通防守战。
- 一场强化战或区域终结战。
- 区域之间的整备、奖励和路线选择。

最后一场为最终 Boss 战。
完整流程约 15–25 分钟。

至少准备九张有明显结构差异的地图模板，再通过受约束的随机变化增加重玩性。

随机内容包括：
- 战役地图组合。
- 部分墙体、掩体与通路。
- 出生方向和敌军组合。
- 可选路线。
- 商店商品。
- 战后奖励。
- 特殊事件。
- 精英修正。

分支需要有真实取舍，例如：
- 危险路线奖励更好。
- 修理路线可以恢复基地或玩家耐久。
- 资源路线敌军更多。
- 特殊事件可以交换资源、获得装备或承担下一战的额外风险。

生成必须保证：
- 玩家能够移动到主要区域。
- 敌军能到达进攻区域。
- 基地附近有合理防守空间。
- 不出现出生即被包围的布局。
- 关键补给和交互点可达。
- 不能仅随机几个箱子就声称每局不同。

十二、局内构筑、技能与商店

战后提供三选一强化，形成不同方向的构筑。

至少设计十二种被动强化，例如：
- 炮弹命中后产生小范围破片。
- 穿透攻击对后续目标保持更高伤害。
- 电弧攻击附加短暂减速。
- 连续命中同一目标增加伤害。
- 击败敌人后恢复少量护盾。
- 移动一段时间后下一发强化。
- 近距离攻击提高破甲能力。
- 基地低耐久时获得紧急支援。
- 冲刺后获得短暂射速提升。
- 破坏地形时获得少量资源。
- 导弹对被标记目标追踪更稳定。
- 护盾破碎时触发一次防御脉冲。

至少制作四种可选择的主动技能：
- 烟幕：降低敌方锁定与命中效率。
- 电磁脉冲：短暂干扰附近机械敌人。
- 维修无人机：持续修复玩家或基地。
- 火力支援：指定区域产生有预警的范围打击。

同一时间装备一种主动技能，拾取新技能时明确替换。

商店可随机出售：
- 武器。
- 被动装备。
- 主动技能。
- 玩家修理。
- 基地修理。
- 护盾补充。
- 下一战的有限支援。

商品有真实图标、武器预览、说明、价格和购买反馈。
不能只显示一行名字，让玩家不知道买到什么。

资源消耗、装备替换和奖励领取需要防止重复执行。

十三、Boss 战

最终 Boss 设计为一辆原创大型攻城指挥车。

需要具有：
- 独立轮廓。
- 多组可辨认武器。
- 履带或机械行走结构。
- 阶段变化。
- 明确弱点。
- 强烈受击与部件损坏反馈。

至少包含三种攻击：
- 蓄力主炮：有炮口蓄光与瞄准预警。
- 导弹齐射：显示落点与延迟。
- 召唤护卫：迫使玩家分配火力。
- 可选横扫激光或冲锋，必须有足够预警。

至少两个阶段：
- 第一阶段强调观察攻击与利用掩体。
- 第二阶段改变武器组合、进攻位置或战场结构。
- 阶段转换不会突然清空玩家护盾或生成必吃伤害。
- Boss 既会威胁玩家，也会对基地形成压力，但攻击节奏需要留出处理空间。

Boss 不只是普通坦克放大并提高耐久。
击败后停止敌方伤害和生成，进入完整胜利演出与结算。

十四、额外模式

除完整战役外，再提供：

1. 无尽防守
- 在选定地图持续抵挡敌军。
- 波次逐渐增强。
- 周期性提供强化和整备。
- 保存最高波次与最佳成绩。

2. 训练场
- 试用不同武器。
- 练习移动、瞄准和技能。
- 测试砖墙、掩体与爆炸物。
- 可以随时退出。

不依赖在线多人或服务器排行榜。
本地纪录需要明确标注，不能把模拟数据伪装为真实玩家。

十五、界面、响应式与操作体验

界面采用克制的工业战术风格：
- 清楚的数字与状态。
- 与坦克和装备一致的填充图标。
- 少量警示色。
- 有材质感但不过度装饰。

避免明显 AI 模板感：
- 不堆叠无意义卡片。
- 不使用满屏玻璃面板。
- 不用过小英文作为装饰。
- 不让大量标签和动画抢占战场。

至少完成：
- 主菜单。
- 模式选择。
- 战役路线。
- 车库与装备预览。
- 战场 HUD。
- 强化选择。
- 商店与事件。
- 暂停。
- 设置与教程。
- 胜负结算。

HUD 清楚显示：
- 玩家耐久和护盾。
- 基地耐久。
- 当前波次与剩余敌人。
- 武器和射击状态。
- 冲刺与技能冷却。
- 货币。
- 进攻方向提示。

适配电脑、横屏手机和横屏平板。
手机竖屏时提供清楚的横屏引导，并妥善暂停当前游戏。
不支持方向锁定时仍可正常使用横屏布局。

双摇杆不能遮住关键进攻方向。
考虑安全区域、浏览器工具栏、屏幕圆角与误触。
提供摇杆大小、位置或透明度的合理设置。

十六、声音、存档与稳定性

声音至少包含：
- 履带与引擎。
- 不同武器射击。
- 命中装甲与墙体。
- 爆炸与连锁爆炸。
- 护盾吸收与破碎。
- 技能。
- 基地警报。
- 波次开始。
- Boss 登场、转阶段和被击败。
- 菜单、购买和强化。

提供音乐与音效独立音量。
正确处理浏览器首次交互、暂停和切后台。

本地保存：
- 当前战役检查点。
- 武器与构筑。
- 资源和基地状态。
- 模式纪录。
- 教程与设置。

继续战役从安全整备点或战斗起点恢复，不在危险帧直接恢复。
存档有独立命名空间和版本号。
损坏存档安全处理，不能导致白屏。

失焦与切后台自动暂停，返回后明确继续。
暂停时同步停止敌人、弹道、技能持续时间和波次计时。

十七、代码解耦与注释

代码应便于其他开发者接手。

分离以下职责：
- 输入适配。
- 坦克移动。
- 炮塔瞄准。
- 武器与弹道。
- 碰撞。
- 耐久与伤害。
- 地形破坏。
- 敌军 AI 与寻路。
- 基地与波次。
- 战役生成。
- 构筑与装备。
- UI。
- 音频与特效。
- 存档。
- 游戏状态。

武器、敌人、技能、奖励和关卡优先使用数据驱动配置。
避免全部逻辑堆进一个超大文件。

为模块、公共接口、数据结构和关键算法编写清楚的中文注释。
重点解释坐标单位、伤害顺序、碰撞规则、炮口检测、寻路更新、奖励防重和存档恢复。

注释解释设计原因和边界条件，不逐行重复代码。

交接文档说明：
- 目录结构。
- 系统关系。
- 如何增加武器、敌人、技能和地图。
- 如何调整平衡。
- 如何运行测试与构建。
- 已知限制。

十八、实际测试与验收

必须启动游戏并实际操作，不仅确认构建成功。

重点验证：
1. 鼠标和双摇杆可以同时移动与射击。
2. 炮塔方向、炮口和弹道一致。
3. 持续射击没有无提示的换弹或停火。
4. 炮口贴墙不会穿墙发射。
5. 高速炮弹不会穿透应阻挡的目标。
6. 伤害、护盾与保护时间有明确反馈。
7. 墙体破坏后更新碰撞和敌军寻路。
8. 敌人不会卡住导致波次无法结束。
9. 基地和玩家的失败结算只执行一次。
10. 武器替换、商店和奖励不会重复扣款或发放。
11. 随机地图可以正常移动和防守。
12. 手机与平板按钮不会互相干扰。
13. 暂停、重开、切后台和存档恢复正确。
14. 长时间游玩不会不断积累弹药、特效和音频对象。
15. 主流程能够从开局完成最终 Boss 战并进入胜利结算。

自动化可辅助验证弹道、生成、状态和奖励逻辑，但不能直接调用胜利函数冒充实际通关。

不能实际验证的设备要明确说明，不得声称已测试。

最终交付：
- 完整源码、素材与项目配置。
- 可构建的静态网页版本。
- 启动与构建命令。
- 本地预览地址。
- 电脑和触屏操作说明。
- README 与交接文档。
- 已实现内容和实际测试结果。
- 明确的已知限制。

最终成果必须是一款非像素风、自由驾驶与独立瞄准、具备可破坏战场、基地防守、随机路线、局内构筑、商店和最终 Boss，并能在电脑与触屏设备完整游玩的坦克动作游戏。
