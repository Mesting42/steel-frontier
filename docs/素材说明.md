# 素材与依赖说明

- 玩家坦克、敌军、Boss、武器、基地、掩体和外围设施：本项目原创程序模型，源码位于 `src/models.ts`、`src/render.ts`。
- 地面、装甲喷漆磨损：本项目原创 Canvas 程序材质；随源码在本地生成，不访问远程服务。
- 射击、履带引擎、爆炸、护盾、技能、警报、菜单与音乐：本项目原创 Web Audio 合成，位于 `src/audio.ts`。
- 界面图标：本项目原创实心 SVG 几何图标，位于 `src/ui.ts`。
- Rajdhani 字体：SIL Open Font License 1.1，通过 `@fontsource/rajdhani` 本地打包；许可证见该依赖目录的 `LICENSE`。中文使用设备已有的雅黑、苹方或系统中文字体，不分发操作系统字体。
- Three.js：MIT 许可证，通用三维渲染库。
- Vite、TypeScript、tsx：开发和构建工具，许可证见各依赖包。

未使用现成完整游戏模板、商业游戏角色、音频采样或第三方游戏美术。
